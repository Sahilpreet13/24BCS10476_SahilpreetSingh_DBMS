# SQL Intermediate - Experiment 4: SQL Joins

## 📌 Overview

This repository contains the solutions for **Experiment 4** of the SQL Intermediate Lab. The experiment focuses on understanding and implementing different types of **SQL JOIN operations** using multiple relational tables.

The queries demonstrate how data from multiple tables can be combined using various join techniques to retrieve meaningful information.

## 📖 Concepts Demonstrated

| JOIN Type | Purpose |
|-----------|---------|
| INNER JOIN | Returns matching records from both tables |
| LEFT JOIN | Returns all records from the left table and matching records from the right table |
| FULL OUTER JOIN | Returns all matching and non-matching records from both tables |
| CROSS JOIN | Returns the Cartesian product of two tables |
| SELF JOIN | Joins a table with itself to compare related rows |
